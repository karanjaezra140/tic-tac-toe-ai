# Tic-Tac-Toe with AI Opponent

A Python console game where a human player competes against an unbeatable AI opponent, powered by the Minimax algorithm.

## Quickstart

**Prerequisites:** Python 3.11 or later. No external libraries required.

**Install:**
```
git clone https://github.com/karanjaezra140/tic-tac-toe-ai.git
cd tic-tac-toe-ai
```

**Run:**
```
python ticktack.py
```

## Features
- Play Tic-Tac-Toe against an unbeatable AI (Minimax algorithm)
- Starting player (human or AI) is randomized each game
- Input validation (rejects invalid or taken moves)
- Win, loss, and draw detection
